## About Me

I'm a freelance full-stack developer focused on financing, accounting, and fintech platforms. My work spans frontend interfaces, backend application logic, and database integration, using both modern web frameworks and established PHP stacks.

- **Education:** Computer Technology graduate, Southern Luzon State University, Lucena City, Philippines.
- **Current focus:** Agricultural financing systems, Laravel and React applications, and blockchain development with Stellar.
- **Outside of engineering:** Photography and creative media.
- **Collaboration:** Open to freelance development projects and technical collaboration.

## What I'm Building

| Project | Overview | Technologies |
| --- | --- | --- |
| **AccountingSystem** | Agricultural financing and accounting platform combining a modern web frontend with an existing PHP and database stack. | Next.js, React, TypeScript, PHP, ADOdb, MySQL |
